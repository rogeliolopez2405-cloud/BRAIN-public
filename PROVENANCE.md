## This is a controlled export

**This public repository is not the complete private development repository.** It is a
deliberately limited export containing architecture documentation, the canonical laws and
limitations, and frozen validation results.

The implementation, the test suite, the validation tooling, the development history and the
recorded world data are not included. That omission is intentional, not an oversight — see
[PUBLIC-SCOPE.md](PUBLIC-SCOPE.md).

The git history of this public repository was created fresh. It is not a filtered copy of the
private history, and no private commit, file or record is recoverable from it.

## What the frozen commits establish

They establish **file identity and a point in time**, not authorship. Anyone can compute the
same hashes from the same bytes; that is what makes them useful for saying "this is the version
that was reviewed". The public commit SHA and the SHA-256 manifest in
[MANIFEST.sha256](MANIFEST.sha256) serve the same purpose for this release.

Authorship is asserted here by the copyright holder — see [COPYRIGHT.md](COPYRIGHT.md) — and by
the private development record, which predates this publication.
